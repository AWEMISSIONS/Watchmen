# Watchmen on the Wall

A static, mobile-friendly archive for the Watchmen reports. It keeps verified developments separate from interpretation and includes the requested standing watch for the November 2–6, 2026 First International Congress of Noahides.

## Run locally
Open `index.html` in a browser. GitHub Pages can serve the repository root; `.github/workflows/pages.yml` can be added after confirming Pages is enabled.

## Reports
The repository includes the latest ten dated PDFs available on October 14, 2026 (October 5–14). Add future reports to the repository root and add their date and filename to the `reports` list in `app.js`. The archive intentionally does not imply that new reports are generated automatically.

## Scope
This is a public static archive. It has no account system, tracking, or automatic news ingestion.
